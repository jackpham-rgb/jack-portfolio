# Jack Pham's Portfolio

Live at https://jackpham-rgb.github.io/jack-portfolio/

Static HTML, CSS and JS with no build step. Edit the files and push to `main` to publish.

## Layout

```
index.html          home: featured projects, About, Skills, Experience, Resume, Contact
project.html        one page per project, opened as project.html?p=<id>
journal.html        dated entries on how each project went, newest first
projects.js         all project content; FEATURED picks the three home page cards
journal.js          journal entries
style.css           the whole look (palette at the top, Arial throughout)
assets/             resume PDF
assets/img/         project photos and figures
assets/img/projects/  figures copied from each project repo
assets/img/life/    photos for the Outside work section
v2/                 redirects old /v2/ links to the main pages
```
