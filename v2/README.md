# Portfolio 2.0

A second version of the site, kept beside the original so the main link does not change until it replaces it.

Live at https://jackpham-rgb.github.io/jack-portfolio/v2/

- `index.html`: home page with featured projects, About, Skills, Experience, Resume and Contact.
- `project.html?p=<id>`: one page per project, in the order Problem, Approach, Result, What broke, Learnt.
- `projects.js`: all project content. Set `FEATURED` to choose the three home page cards.
- `journal.html` and `journal.js`: dated entries on how each project went, newest first.
- `style.css`: the whole look. The palette and fonts are listed at the top.
- Images are in `../assets/img/v2/`.
